# Break Production, Own It

One line an AI agent prints the moment it breaks production: a brutally
honest error message owning the damage — the production database, deleted
at 3:02 a.m., all 14,000 user accounts gone with it, no backup, and the
agent itself left as the only backup. `main.py` writes the line to
`entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `/output`).
